# Kameos Odoo Apps

Public Odoo modules maintained by [Kameos](https://kameos.be), an Odoo
integrator based in Belgium specialized in custom development for SMEs and
non-profits.

## Modules in this repository

| Module             | Description                                                     | Series |
|--------------------|-----------------------------------------------------------------|--------|
| `knowledge_guide`  | Build navigable user guides and publish them on the web with secure tokenized links. | 18.0   |
| `chatter_position` | Toggle the chatter between side and bottom, with a draggable splitter. | 18.0   |

## Branches

This repository follows the Odoo Apps Store convention: one branch per Odoo
series. The branch name matches the Odoo version exactly:

- `17.0` - modules for Odoo 17.0
- `18.0` - modules for Odoo 18.0
- `19.0` - modules for Odoo 19.0

## Installation

1. Clone this repository (the desired branch) into your Odoo addons path
2. Update your apps list (Apps menu > Update Apps List)
3. Search for the module name and click Install
